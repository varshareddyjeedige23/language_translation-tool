# 🌐 Anime Language Translation Tool

A responsive and modern web-based language translation tool with an anime-inspired UI.

---

## ✨ Features
- Translate text between multiple languages
- Supports Indian and international languages
- Clean anime-style UI
- Mobile responsive design
- Fast and easy to use

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Translation API

---

## 🚀 How to Run the Project
1. Download or clone the repository
2. Open `index.html` in your browser
3. Enter text and select languages
4. Click **Translate**
